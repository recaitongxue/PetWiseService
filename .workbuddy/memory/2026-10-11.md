## 第二轮：登录 + 导航固定（同日晚）
用户要求：参考真实流行 App、加登录、底部导航不随页面滚动。

1. **导航固定根因修复（base.css）**：`.app-main` 是 flex 子项且缺 `min-height:0`，内容把它撑高 → 外壳 `min-height:100vh` 被突破 → 整页滚动，absolute 定位的 Dock 跟着跑。修复：外壳 `height:100dvh` 锁死（桌面 `calc(100dvh - 48px)`）+ `.app-main` 加 `min-height:0` + `#app` 锁高 `overflow:hidden`。实测滚动后 dock 位移 0px。
2. **切页滚动残留修复（App.vue）**：滚动容器是 .app-main，vue-router 的 scrollBehavior 管不到 → 路由切换后滚动位置残留。加 `watch(route.path)` 归零。
3. **新增 Login.vue（/login，meta.bare）**：按主流规范——居中表单型布局、验证码/密码分段切换、+86 手机号（inputmode=numeric 实时校验 1[3-9]\d{9}）、60s 倒计时、密码眼睛切换、协议勾选（未勾选拦截）、加载态按钮、注册/忘记密码占位、微信第三方。演示：任意合法手机号 + 6 位验证码即登录。

## 问诊模块重点增强（第三轮：结构化预问诊 + 报告闭环）
用户明确「问诊模块是毕设重点功能」，选定方向：向导式结构化预问诊 + 问诊报告与档案闭环（不做医生端）。

1. **数据层**：mock.js 新增 bodyParts（8 部位 → 40+ 症状，含 redFlag 高危标记与 weight 加权）、durations、severities、accompanyOptions（均带权重 w）
2. **src/data/triage.js（新增独立分诊引擎）**：scoreTriage(answers) 输出 level/score/factors/causes/actions/followUp
   - 高危信号一票否决直接判 emergency；其余按 时长+严重程度+症状加权+伴随症状 累加，阈值 >=3 判 urgent
   - factors 逐项可回溯（"已持续超过一周 +3"），避免黑盒打分；CAUSE_MAP 为症状→可能原因知识库
   - 独立成模块便于论文阐述，接入真实模型后可平滑替换为「模型输出 + 规则兜底」
3. **PreConsult.vue（/preconsult 7 步向导）**：宠物→部位→症状→时长→严重程度→伴随→补充；进度条 + 上下步；选中 redFlag 即时弹高危告警条（不打断问卷，报告可带给医生）；末步生成报告并跳转
4. **ops.js 报告层**：REPORT_KEY='petwise_consult_reports'；saveReport/markReport/archiveReport（写入健康档案，复用 addRecord）/remindFromReport（处方与复查转日程，复用 addScheduleItem）
5. **Report.vue（/report/:id）**：封面（AI 预问诊 / 真人医生两类）+ 结构化主诉 + 分诊结论（复用 TriageCard）+ **评分依据可展开** + 医生建议 + 用药方案 + 复查计划；底部三操作：转真人医生 / 存入档案 / 用药提醒（已执行则置灰防重复）
6. **闭环打通**：真人问诊室结束评价后自动生成 human 类型报告（含医生文字建议与处方）并跳转；Records.vue 合并 reports() 列表，点击进报告；问诊页与记录页均加「结构化问诊」引导入口

### 踩坑记录（重要）
Vue 3 script setup 模板中 ref 会自动解包：`@click="toggle(symptomIds, s.id)"` 传入的是普通数组而非 ref，函数内用 `list.value` 会 undefined 报错且**静默失效**（点击无反应、无可见报错）。改为显式 `toggleSymptom(id)` / `toggleAccompany(id)` 直接操作 ref.value。

验证：check-preconsult.cjs 24 项全 PASS（含红旗中断、加权评分=10、存档→档案页可见、提醒→日程页可见）；check-consult.cjs 回归 33 项全 PASS（真人问诊结束→报告含建议与处方→可存档）。
