# 2026-10-16 前后端联调：前端整体接入真实 API

## 目标
把 apps/mobile 从 `data/mock.js` + `data/ops.js`（localStorage）整体切到真实后端，完成端到端联调。

## 新增的基础设施（前端）
- `src/api/data.js`：**数据门面**，所有视图唯一的数据来源。把后端 ORM 序列化的形状归一成原 mock 的形状，
  降低各视图改动量（如 `fetchPetSchedule()` 返回按 petId 分组的 map，对应原 `petSchedule[id]`；
  `fetchHealthRecords` 给 `value` 别名 = weight；`fetchRecognitionHistory` 给 `date` 别名 = time）。
- `src/api/client.js`：纯客户端能力（ops.js 里确实没有后端对应的部分）——短信每日频控、钱包流水、isAuthed。
- `src/composables/useAsync.js`：可选的组合式，多数视图直接用 `ref + onMounted`。
- `index.js` 补齐：`contactsApi`、`imApi.create`、`memoApi`、`recognitionApi.correct`、
  `communityApi.report`、`scheduleApi.aiPlan/batch`；`contentApi.addFavorite` 透传 meta。

## 铁律（本项目已定稿）
- **`data/ops.js` 已废弃**，全仓不再有任何 .vue 引用它（含 router/index.js 的 `isAuthed`）。
- **`@/data/mock` 只保留静态配置**：quickActions, tips, consultSeed, consultSuggestions,
  departments, consultModes, bodyParts, durations, severities, accompanyOptions,
  symptomGroups, triageRules, aiSchedulePlan, galleryPool, recognitionSamples。
  其余一律走 API。
- 同步 → 异步：mock 常量一律改成 `ref`，在 `onMounted` 里加载；computed/函数体用 `.value`；
  给 computed 一个安全空形状兜底，避免数据到达前模板取字段崩。

## 后端修的问题
1. `GET /pets/{id}/records` **双层信封**：`ok(paged(...))` → paged() 内部已包 ok()，改掉后
   前端拿到的才是 `{list,...}`（否则 `r.list` undefined → `.map` 崩）。
   注意：`paged()` 的 total/page/page_size 是 **关键字参数**，位置传参会 500。
2. `POST /consult/triage` 之前不扣额度（left 永不减），新增 `_consume_ai_quota`；额度为 0 时抛 CONFLICT。
3. `GET /favorites` 的 `_shape()` 补 `targetId`：前端删除走 `DELETE /favorites/{kind}/{target_id}`，
   缺该字段会静默删不掉。
4. `pre-consult` 的 chief 优先取前端传的可读中文标签（否则报告里只剩 `skin-itch` 这类 id）。
