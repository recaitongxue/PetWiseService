# 2026-10-13

## 宠物识别模型精度提升改造（PetWise / cv）

用户反馈猫模型 Top-1 仅 54.89%（评测报告显示十几个品种召回率 0%，长尾崩），狗 val 85.27%，要求显著提升精度、指标多样化、写论文需引用。已确认训练算力为双 RTX 5090（32GB×2），创新取向=强骨干+轻量自研损失。

### 改动（均落在 common/ 内核，狗猫共用）
- `common/models/factory.py`：新增强骨干 convnext_base/large、swin_b、efficientnet_v2_l、vit_b_16、maxvit_t（分类头替换已验证可构造）。
- `common/models/loss.py`（新）：FocalLoss + ClassBalancedFocalLoss（Cui 2019 有效样本数），论文创新点"改进的损失与训练策略"。
- `common/train/trainer.py`：可插拔损失、DDP 包裹(EMA兼容)、梯度累积 grad_accum、主进程写文件守卫。
- `common/train/cli.py`：torchrun DDP 检测、分布式类平衡采样器、class_counts 传入、调用 evaluate_full，修复狗猫评测报告同名覆盖 bug（现 eval-report-<kind>-<split>-full.*）。
- `common/eval/evaluate.py`：evaluate_full 论文级指标（P/R/F1 macro/micro/weighted、平衡准确率、Cohen κ、ROC-AUC-OvR、头中尾分段精度、混淆矩阵 CSV+PNG）。
- `common/data/transforms.py`：randaug 增强；`common/data/sampler.py`：DistributedWeightedSampler。
- 配置：`dog/cat/configs/dataset.yaml` image_size 224→384、batch 48；新增 `train-HIGH.yaml`（狗 convnext_large / 猫 efficientnet_v2_l，均为 cb_focal+randaug+cutmix+384）。
- `scripts/train.sh`：支持 HIGH/BASE 预设 + 多卡 torchrun DDP 自动启动。
- `pyproject.toml`：加 scikit-learn、matplotlib。
- `docs/references.bib`（BibTeX）、`docs/方法论与引用.md`（方法章节草稿+技术→文献映射+消融设计+复现命令）。

### 验证
- 本机无 GPU、torch 仅 CPU 且 oneDNN 受限（卷积前向报 could not create a primitive，属环境限制不影响 GPU）。
- py_compile 全过；CPU 冒烟验证：16 个骨干均可构造、Focal/CB-Focal 损失可计算、DistributedWeightedSampler 双卡分片正确、evaluate_full 基础路径跑通。
- **sklearn 丰富指标路径已复验通过**（venv 装好 sklearn 1.9.1 / matplotlib 3.11.2）：evaluate_full 正确输出 balancedAccuracy、cohenKappa、rocAucMacroOvR、segmentAccuracy(头/中/尾)、precision/recall/f1(macro/micro/weighted)、confusionCsv/PNG 等全部论文级指标。SMOKE_OK。
